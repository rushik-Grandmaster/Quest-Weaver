## Packages
framer-motion | Essential for smooth XP bar animations, leveling up effects, and page transitions
date-fns | Formatting dates for tasks and schedule
react-day-picker | Calendar component for the schedule view
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging tailwind classes

## Notes
The app uses Replit Auth.
Backend provides standard CRUD endpoints for tasks, shop, inventory, and schedule.
Gamification logic (XP, leveling) happens on the backend, but frontend needs to visualize it beautifully.
Dark mode is preferred for the "gaming" aesthetic.
